## 🔄 Как обновить цены в меню

Меню находится в файле **`menu.json`**. Его можно открыть в любом текстовом редакторе (Блокнот, VS Code, даже на телефоне).

### Формат файла:
```json
{
  "name": "Капучино",
  "desc": "Описание напитка",
  "price": 180,
  "emoji": "☕",
  "tag": "Хит"
}
```

### Что можно менять:
| Поле | Что это | Пример |
|------|---------|--------|
| `name` | Название позиции | `"Капучино"` |
| `desc` | Описание | `"Нежная молочная пена"` |
| `price` | Цена в рублях (только число) | `180` |
| `emoji` | Иконка | `"☕"` |
| `tag` | Бейдж «Хит» (или пустой) | `"Хит"` или `""` |

### Как добавить новую позицию:
Вставьте новый блок в массив `items` нужной категории:
```json
{ "name": "Новинка", "desc": "Описание", "price": 250, "emoji": "✨", "tag": "Новое" }
```

### Как удалить позицию:
Просто удалите блок `{ ... }` соответствующей позиции из массива.

> ⚠️ После изменения `menu.json` — загрузите обновлённый файл на хостинг (через GitHub или FTP).
